 Restaurant POS System

 About the Project

A web-based Point of Sale (POS) system developed as a Final Year Project (PFE).

The application aims to provide a digital solution for restaurant management using a modern frontend and backend architecture.

 Technologies

- Frontend: React.js, JavaScript, Vite
- Backend: Java, Spring Boot
- Database: MySQL

 Architecture

The project follows a client-server architecture:

- React.js for the user interface.
- Spring Boot for backend development.
- MySQL for data storage.

 Project Context

Final Year Project (PFE)

Collaborative development project.

 Development

This project was developed collaboratively as part of an academic project.
